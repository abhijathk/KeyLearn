Goal report — landscape variants

The live GoalCeremony card is a single fixed-width (21rem) column with no max block-size — every section stacks vertically, so its total height is just the sum of all of them. On a short laptop viewport in landscape, that overflows. Same content, same copy, same tokens and component classes below — only the arrangement changes, using the width a landscape screen actually has.

ATwo columns — closest to today's card

Left: identity + stats + actions, in the same order as today. Right: trend + focus + encouragement + quote. Roughly halves the height with the smallest layout departure from what already exists.

Which to build

A is the safe pick — same visual rhythm as the live card, easiest review, height cut roughly in half. B goes further for genuinely short viewports at the cost of a slightly busier three-way split. C solves height almost completely but reads more like a status bar than the "ceremony" moment the current design is going for — I'd hold that one back unless height is still a problem after A or B.
